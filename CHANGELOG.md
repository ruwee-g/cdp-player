# Changelog

## v0.1.0 — first public release

- Frameless transparent player window (drag by the body or the disc)
- Local audio: mp3, flac, wav, m4a/aac, ogg/opus, aiff, mp4/m4v
- File picker (multi-select), drag & drop, Finder's Open With / double-click
  (single instance: files land in the running window)
- Branded spinning disc with inertia, 4 cover visualizer modes
  (trackpad swipe to switch), dot-matrix volume meter
- Idle animations on pause (heart, sleepy, cassette, rocket, tetris,
  fireworks, umbrella)
- Repeat off / all / one, seek, volume + mouse-wheel volume
- Keyboard shortcuts: Space, arrows (+Shift seek), M mute
- Persisted library, volume and repeat mode
- Tag + cover-art reading (Rust/lofty)
